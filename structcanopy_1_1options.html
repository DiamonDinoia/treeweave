Detailed Description

Runtime fit knobs. Every field here only affects fit-time construction; there is no eval-time benefit to promoting any of them to a template parameter, so they stay plain data.

◆ allow_max_depth_leaves

bool canopy::options::allow_max_depth_leaves = false

When true, panels that fail tolerance at max_depth are kept as best-effort leaves. Inspect them via Function::non_converged_panels(). Default false (throw, with the panel list attached on the exception).

◆ max_depth

int canopy::options::max_depth = 50

Tree-depth ceiling for the adaptive paneler. Hitting it without converging throws MaxDepthExceeded (or, with allow_max_depth_leaves, accepts the panel as best-effort). 50 is far above what any non-singular function needs; lower it to fail fast when a near-singularity is suspected.

◆ max_memory_mib

int canopy::options::max_memory_mib = -1

Hard cap on accumulated leaf storage during the fit, in MiB. Tri-state:

  • < 0 (default) — auto: a small, dimension-scaled budget, 4 << (input_dim-1) MiB (4 / 8 / 16 for 1D / 2D / 3D). Leaf storage grows ~geometrically with input_dim, so a single flat cap is either too loose in 1D or too tight in 3D; scaling keeps the default a genuine guardrail in every dimension.
  • 0 — disabled (no cap).
  • > 0 — explicit cap in MiB. The default is deliberately small so an adaptive paneler can't quietly grow into hundreds of MiB; ambitious 3D+ or oscillatory fits opt in explicitly with a larger value (or 0). Crossing the cap throws MemoryBudgetExceeded, which carries the used/budget bytes and the offending panel so the caller can raise the budget or excise the singular region.

◆ min_uniform_depth

int canopy::options::min_uniform_depth = 0

Force BFS to refine every panel to at least this depth before the per-panel tolerance test exits. Useful for driving the leaf-table fast path (PolyTree::quantize_one): a uniformly- refined tree of depth D in input_dim K builds a 2^(K*D)-entry quantize table the eval-time lookup collapses to one SIMD quantize + one u32 load. Table size grows as 2^(K*D) * 4 B and is capped at 64 K entries (256 KiB) per subtree, so values that push past K*D > 16 will still build a uniform tree but not the table. Default 0 (no forcing — tol-based refinement only).

◆ tol_kind

TolKind canopy::options::tol_kind = TolKind::RelativeMax

How tol is interpreted by the convergence check. The default (RelativeMax) compares max-abs error on a sample grid against tol * max(|f|); switch to Absolute* when f can be zero or when relative accuracy isn't meaningful.
