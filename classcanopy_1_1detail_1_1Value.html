Detailed Description

template<typename T, std::size_t N>
class canopy::detail::Value< T, N >

Scalar/array uniform wrapper. Behaves as a scalar when N == 1 and as a std::array<T, N> otherwise, exposing the same arithmetic operators in both forms so the rest of canopy can be written dim-agnostic. The four elementwise binary operators all funnel through apply / apply_scalar, which lets the optimiser see one inlined loop per op rather than four duplicated bodies.
