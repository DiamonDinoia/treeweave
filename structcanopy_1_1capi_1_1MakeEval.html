Detailed Description

template<class T, std::size_t IN>
struct canopy::capi::MakeEval< T, IN >

xsimd::dispatch functor for a fixed (value_type, input_dim). Stores the fit arguments; operator()(Arch) is invoked by xsimd for the widest arch the host CPU supports and forwards to make_eval_for<Arch, T, IN, / chosen_degree<Arch,T,IN>>(…). Degree is baked — the functor carries no degree field.
