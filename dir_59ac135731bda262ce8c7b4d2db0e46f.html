Detailed Description

A thin Fortran 2008 wrapper over the canopy C ABI (../../include/canopy.h), built on the intrinsic iso_c_binding module. Every C entry point is exposed as a Fortran procedure of the same name, so the mapping is one-to-one and explicit.

Unlike the Python / Julia / MATLAB wrappers, this binding is deliberately faithful rather than ergonomic: there is no call operator, no keyword arguments, and no dimension inference. The caller passes input_dim / output_dim explicitly, exactly as a C consumer would.

Using it

use, intrinsic :: iso_c_binding
use canopy

  1. Write your target as a bind(C) procedure matching the C callback void f(const double *x, double *y, void *context):

    subroutine kernel(x, y, context) bind(C)
    use, intrinsic :: iso_c_binding
    real(c_double), intent(in) :: x(*) ! input_dim coordinates
    real(c_double), intent(out) :: y(*) ! output_dim results
    type(c_ptr), value :: context
    y(1) = exp(x(1))
    end subroutine

    Callbacks must be bind(C) so c_funloc() yields a C-callable pointer; module procedures are the cleanest way to provide them. The canopyf_* twins use real(c_float) for x/y.

  2. Fit, passing c_funloc(kernel). Pass c_null_ptr for opts to use canopy_default_opts, or c_loc(my_opts) with a target canopy_opts:

    real(c_double) :: a(1) = [0.0_c_double], b(1) = [1.0_c_double]
    type(c_ptr) :: h
    h = canopy_fit(c_funloc(kernel), 1_c_int, 1_c_int, a, b, 1.0e-10_c_double, &
    c_null_ptr, c_null_ptr)
    if (.not. c_associated(h)) then
    write (*,'(2A)') "fit failed: ", canopy_error_message()
    error stop 1
    end if

  3. Evaluate, then free:

    real(c_double) :: x(1) = [0.5_c_double], y(1)
    call canopy_eval(h, x, y) ! single point
    call canopy_batch(h, xs, res, n) ! n points, AoS (n: integer(c_size_t))
    h = canopy_free(h) ! returns c_null_ptr

The context pattern

A Fortran bind(C) procedure cannot capture state, so context is the stand-in for a closure's captures (mirroring examples/C/with_context.c). Put the state in a bind(C) derived type, pass c_loc() of a target instance, and recover it inside the callback with c_f_pointer:

type, bind(C) :: params_t
real(c_double) :: amplitude
real(c_double) :: frequency
end type
subroutine kernel_ctx(x, y, context) bind(C)
real(c_double), intent(in) :: x(*)
real(c_double), intent(out) :: y(*)
type(c_ptr), value :: context
type(params_t), pointer :: p
call c_f_pointer(context, p)
y(1) = p%amplitude * sin(p%frequency * x(1))
end subroutine
! ... in the caller:
type(params_t), target :: params
params%amplitude = 2.5_c_double; params%frequency = 7.0_c_double
h = canopy_fit(c_funloc(kernel_ctx), 1_c_int, 1_c_int, a, b, tol, &
c_loc(params), c_null_ptr)

The canopy_* procedures operate on double; the canopyf_* twins (fit + the eval family) on float. Introspection and lifetime (canopy_dtype, canopy_input_dim, canopy_output_dim, canopy_memory_usage, canopy_print_stats, canopy_free) are dtype-independent — no canopyf_ twin.

Build

The binding is wired into the top-level CMake behind CANOPY_BUILD_FORTRAN (default OFF). It builds a self-checking test (canopy_fortran_test) and an example (canopy_fortran_example), both linking the shared canopy_c:

cmake -S . -B build -DCANOPY_BUILD_FORTRAN=ON
cmake --build build --target canopy_fortran_test canopy_fortran_example
ctest --test-dir build -R fortran_canopy --output-on-failure

A missing Fortran compiler degrades to a STATUS message and a skipped test.
