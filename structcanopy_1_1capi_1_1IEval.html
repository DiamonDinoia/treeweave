Detailed Description

template<class T>
struct canopy::capi::IEval< T >

Runtime-polymorphic evaluator interface for value type T. One concrete EvalImpl per supported (IN, OUT, Policy) implements it; the C shims hold an IEval<T>* behind the opaque handle. Only scalar const T*/T* cross this interface, so no SIMD type — and therefore no arch-dependent sizeof — ever crosses a TU boundary.
